# Design tokens

> [Back to BizSaathi overview](../../../README.md)

This directory contains shared style-token definitions, including design-token modules.

## Architecture and use

Use the established tokens when an active frontend surface imports them. Avoid creating a second source of truth for values already defined in the main app stylesheet or another token file.

## Metrics and impact

No styling or accessibility metrics are recorded here. Shared tokens can improve consistency, but measurable accessibility and usability outcomes require separate evaluation.
