# Post routes

This route group supports viewing and preparing social/content post drafts.

## Architecture and use

Drafts use backend-generated or seller-provided content and should retain review and evidence information where available. Publishing externally is not implied; real social publishing integrations are future scope unless explicitly implemented and verified.

## Metrics and impact

No publishing, engagement, or content-quality metrics are recorded. The intended value is reducing manual content preparation while preserving owner review.
