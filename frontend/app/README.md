# Next.js application routes

`app/` is the active App Router tree for the frontend. Route folders implement seller pages and public store pages; shared UI, authentication context, and API helpers support those routes.

## Route groups

`approvals/`, `login/`, `messages/`, `offline/`, `orders/`, `posts/`, `products/`, `store/`, and `trace/` hold route-level experiences. `components/`, `context/`, and `lib/` contain shared application pieces.

## Stack, metrics, and impact

Next.js App Router, React, TypeScript, and Tailwind CSS. No route-level usage or performance metrics are recorded. This layer turns backend workflows into usable owner and customer experiences; it does not replace backend authorization or confirmation.
