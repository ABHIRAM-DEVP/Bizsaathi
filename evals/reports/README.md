# Evaluation reports

> [Back to BizSaathi overview](../../README.md)

This directory is reserved for per-run evaluation output. Each report should identify run date, workflow/model configuration, and whether the result is mock or live.

## Use

Retain failures as well as successes and compare only runs with compatible datasets and configurations. Do not present mock results as live-model quality.

## Metrics and impact

Reports are the evidence for measured evaluation metrics. If no report exists for a metric, treat its result as unknown; configured thresholds alone are not measurements.
