## 2. CRITICAL DECISIONS (NON-NEGOTIABLE)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  D-01: NO PAID META API USAGE. No Meta-branded model calls. The user provides
        their own API key via .env. The adapter is generic ("AI Model")
        behind one interface at backend/app/ai/. Default mode is MOCK.

  D-02: API key comes from .env only (MODEL_API_KEY, MODEL_BASE_URL).
        Config: backend/app/core/config.py -> Settings.MODEL_PROVIDER (default "mock"),
        Settings.MODEL_API_KEY, Settings.MODEL_BASE_URL.
        .env is .gitignored and must NEVER be committed.

  D-03: Keys stay server-side. Nothing secret in NEXT_PUBLIC_*, logs, traces, git.

  D-04: Every factual claim in generated content carries evidence IDs.
        No evidence → block or escalate (fail closed).

  D-05: Writer, verifier, critic and policy gate are separate controls.
        A node never certifies its own output.

  D-06: Tenant isolation (business_id) enforced server-side on every query/tool.
        Negative tests required.

  D-07: Social webhooks, real payments, KYC are FUTURE. Do not present mocks
        as working.

  D-08: Retries and repair loops bounded (default max 2). Then escalate or stop.
