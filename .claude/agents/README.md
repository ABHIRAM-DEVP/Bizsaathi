# Agent instructions

> [Back to BizSaathi overview](../../README.md)

This directory defines specialized agent roles for implementation, security review, and evaluation analysis.

## Architecture and use

These are instruction files for development-time agents, not application agents that run in production. Invoke a role only for its documented scope and follow repository-wide instructions.

## Metrics and impact

No agent accuracy or productivity metrics are recorded. The intended value is focused, repeatable engineering assistance.
