# Scoped engineering rules

> [Back to BizSaathi overview](../../README.md)

This directory contains topic-specific instructions for agents working in the API, agents, data/tenancy, model adapters, security, testing, evaluation, formats, and web/PWA code.

## Architecture and use

Rules supplement the project contract and load for matching file scopes. If a rule conflicts with current architecture or an explicit task, stop and resolve the conflict rather than silently weakening a safety requirement.

## Metrics and impact

These documents do not provide runtime measurements. Their value is making implementation and review expectations explicit across subsystems.
