# Status notes

This folder contains task- or milestone-specific status reports. Treat these as dated snapshots rather than authoritative current system configuration.

## Use

For current behavior, prefer code, tests, endpoint specifications, and architecture documents. Update or label status reports with their date and verification evidence; do not copy old pass/fail claims forward without rerunning the checks.

## Metrics and impact

Any numbers in status files are scoped to their reported run. No aggregate production impact metric is maintained here.
